# REITs经营驱动与估值桥

| 业态 | 先取证 | 现金及反证 |
|---|---|---|
| 园区与仓储 | 出租率、租金、到期租约、租户集中、免租 | 收缴、应收、空置爬坡、改造开支及同区域供给 |
| 保障性租赁住房 | 出租、限价、调价条件与补贴 | 实际回款、政策有效期及退出限制 |
| 消费基础设施 | 客流、销售、固定租金与抽成、租户销售 | 保底条款、闭店、收缴、免租和维护投入 |
| 公路 | 车型车流、收费、竞争路网、剩余特许期 | 免费通行、维修投入、到期处置；不假定续期 |
| 能源 | 实际发电、利用小时、电价、结算和设备状态 | 弃电、应收、补贴、检修与设备更换 |
| 环保 | 实际处理量、收费合同、项目进度 | 收缴、监管改造、合同资产、恢复义务 |

NOI属于项目运营口径，收入减对应运营费用；基金管理费用、融资、税和资本开支须另外核对。NOI、EBITDA、项目自由现金和可供分配不是通用线性等式，必须依据项目及基金披露逐项桥接。租户销售或车流上涨不自动等于可供分配上涨。

资本化率比较仅在资产、剩余期限、收入与费用范围可比时使用；有限经营权不能套永续NOI/资本化率。已有估值工具接受明确项目现金流与假设，不因本页存在就认证真实底稿完整。术语参考：[Nareit NOI](https://www.reit.com/glossary/net-operating-income)，仅作概念参照，不当作中国可供分配规则。
